## Классы

| Класс          | Роль в иерархии                                                |
|----------------|----------------------------------------------------------------|
| `BaggageTag`   | багажная бирка — часть места багажа (**композиция**)           |
| `BaggagePiece` | место багажа — целое для бирки, агрегируемый объект для рейса  |
| `Flight`       | рейс — агрегатор мест багажа (**агрегация**)                   |
| `BaggageLog`   | журнал оформления — вспомогательный ресурс для демонстрации `AutoCloseable` |

Композиция и агрегация в Java устроены иначе, чем в C++: в обоих случаях
поле хранит **ссылку**, и различие остаётся только в том, **кто создаёт
объект**. Место багажа создаёт свою бирку само, в своём конструкторе, и
наружу её не отдаёт (композиция); места багажа создаются снаружи и
передаются рейсу готовыми (агрегация).

## Сборка и запуск

Нужен JDK 17 или новее; среда разработки не требуется. Из корня репозитория:

    javac -encoding UTF-8 -d out java\src\baggage\*.java java\src\*.java
    java -Dfile.encoding=UTF-8 -cp out Main

Если в консоли Windows вместо русских букв вопросительные знаки — выполните
перед запуском `chcp 65001`. Папка `out/` в репозиторий не попадает
(см. `.gitignore`).

Эталонный вывод программы — в файле `java/console_output.txt`.

## Демонстрации работы с памятью (разделы 5–9 программы)

- **ссылки и копии** (раздел 5) — присваивание копирует ссылку, а не объект:
  изменение веса через вторую переменную видно через первую,
  `first == second` — `true`, потому что это один и тот же объект;
- **освобождение ресурса без деструктора** (раздел 6) — `BaggageLog`
  реализует `AutoCloseable`; блок try-with-resources гарантированно вызывает
  `close()` при выходе, что видно по выводу;
- **сборщик мусора** (разделы 7–8) — объект, на который не осталось ссылок,
  уничтожается не при выходе из блока, а после сборки мусора; наблюдение
  ведётся через `WeakReference`. Сообщений деструкторов в Java нет —
  в отличие от ЛР 2, момент уничтожения объекта заранее неизвестен.
