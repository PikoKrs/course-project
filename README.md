# Лабораторная работа № 2. Классы, агрегация и композиция

Выполнил: Кривов Д. Р., группа ПИ-53, вариант 98.
Тема курсового проекта: «Проектирование автоматизированной системы контроля
и обработки багажа авиапассажиров».

Работа выполняется в ветке `lab-02` и попадает в `main` через pull request.

## Классы

| Класс          | Роль в иерархии                                             |
|----------------|-------------------------------------------------------------|
| `BaggageTag`   | багажная бирка — часть места багажа (**композиция**)        |
| `BaggagePiece` | место багажа — целое для бирки, агрегируемый объект для рейса |
| `Flight`       | рейс — агрегатор мест багажа (**агрегация**)                |

## Сборка и запуск

MSVC (x64 Native Tools Command Prompt):

    cl /nologo /EHsc /utf-8 /std:c++17 main.cpp baggage_tag.cpp baggage_piece.cpp flight.cpp /Fe:lab02.exe
    lab02.exe

MinGW g++:

    g++ -std=c++17 -Wall main.cpp baggage_tag.cpp baggage_piece.cpp flight.cpp -o lab02
    ./lab02

Эталонный вывод программы — в файле `console_output.txt`.
